# dsh-sidebar-tidy

**把 DSH 左侧栏收拾干净：只留工作区。**

DSH 左侧栏顶部那一组入口（插件、自动化任务、上下文洞察、任务看板、更多）是固定的，收不起来，常年占着一百八十多像素。再加上品牌行、新会话按钮和底部的设置，真正留给会话列表的地方就没多少了 —— 会话一多，列表被挤成窄窄一条，翻起来挺烦。

这个小插件把那些东西默认收起来。左边只剩你的工作区和会话，清爽很多。想设置、想切面板，最底下点一下，它们就都回来了。

## 你会多出三样东西

### 一、侧栏只剩工作区

```
工作区
  qinggui
  qz-all
  …

────────────────
↩ 退出极简
```

原来那一堆入口、品牌行、新会话、设置按钮都收起来了。最底下一行「退出极简」，随时全叫回来。

### 二、工作区前面多一个彩色缩写块

```
[QA]  qz-all
[S]   skills
[非]  非开发类文档
```

它顶掉了原来那个千篇一律的文件夹图标，一行只占一个位置。

项目一多，靠颜色和字母扫一眼就知道是哪个。缩写规矩跟 IDEA 那套一样：`smart_radar` → `SR`、`qinggui` → `Q`、中文取第一个字。

颜色默认按名字算，同一个工作区永远是同一个色，换电脑也一样；不喜欢就点它自己改。

### 三、给会话刷底色

在会话后面点 `⋯` → 「标色…」→ 挑个颜色，整行就染上了。

```
[QA]  qz-all
      新海外站_管理端        ← 标过：整行淡红
      新海外站_前端          ← 标过：整行淡黄
      海外站_原始版本        ← 没标：原样
```

不想标就一直是原样 —— **默认一条都不上色**，不会自动把整个列表刷成彩色的。

颜色是半透明叠在行上面的，所以鼠标划过去、选中它、打开菜单，原来的效果都还在。

## 用起来

- 装好就是"收起来"的样子，不用配置任何东西。
- 点最底下的「退出极简」全部回来。回来之后，那组入口上方会多一条标题栏：左边点它收起 / 展开，右边小字再进极简。
- 标题栏中间还有两个开关，`缩写` 和 `标色`，随时关掉其中一个。
- 你点过什么它就记什么，刷新、切会话、切主题都保持。

## 装上

```bash
git clone git@github.com:LoktLin/dsh-sidebar-tidy.git
dsh plugin --profile web add ./dsh-sidebar-tidy
```

装完重启一次 `dsh web`，再刷新页面。

## 几个常见问题

**会不会把 DSH 弄坏？**
不会。它不替换任何官方文件，只是往侧栏里多放一条标题栏、往会话行上加一层底色。卸载之后侧栏就是原样。

**跟换主题打架吗？**
不打架，颜色都跟着主题走。

**隐私模式 / 沙箱里能用吗？**
能用。只是记不住你选的，下次打开回到默认；点一下仍然当场生效。

**侧栏整体收成窄条呢？**
它跟着变窄，只留一个箭头。

**能只收起那组入口、别的不动吗？**
能。退出极简之后点标题栏左边那下就是。

## 想改代码的话

- `lib/client.js` 是全部前端逻辑，没有构建步骤；`lib/index.js` 只提供一个状态路由，不注册工具、不加系统提示。
- 定位那组入口不靠类名里的哈希，只用 `nav` 加 `panelList` 这个片段；万一官方改了，退一步按入口文字找。
- 折叠和隐藏都是给元素打 `data-*` 属性，不用内联样式 —— React 重渲染会覆盖样式，但不会碰自定义属性。
- 自检：`npm test`，纯离线、不碰网络。
- 排障：`curl http://127.0.0.1:3080/sidebar-tidy/status`，或在浏览器控制台跑 `window.__dshSidebarTidy.status()`。
- 状态都存在浏览器 `localStorage`：`dsh.sidebarTidy.zen`（极简）、`.folded`（折叠）、`.abbr`（缩写开关）、`.color`（标色开关）、`.marks`（你标的颜色）。
